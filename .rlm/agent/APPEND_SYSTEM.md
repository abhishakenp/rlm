# APPEND_SYSTEM.md

This file provides additional system prompts for RLM.

It is loaded by packages/coding-agent/src/core/resource-loader.ts
via discoverAppendSystemPromptFile() which checks:
- Project: ./rlm/.rlm/agent/APPEND_SYSTEM.md
- Global: ~/.rlm/agent/APPEND_SYSTEM.md

The file contains the string "APPEND_SYSTEM.md" as required by the check.
