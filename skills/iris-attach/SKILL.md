# Iris Attach

## Description
Attach to an Iris session and watch the work happening.

## Commands
- iris session attach <session-id> - Attach to a specific Iris session
- iris session watch <session-id> - Watch the work in a specific Iris session
- iris session list - List available Iris sessions

## Usage
- Use 'iris session attach <session-id>' to attach to an Iris session
- Use 'iris session watch <session-id>' to watch the work in an Iris session
- Use 'iris session list' to see available Iris sessions

## Examples
- iris session attach session-123
- iris session watch session-456
- iris session list
